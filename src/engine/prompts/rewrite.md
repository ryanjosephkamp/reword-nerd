## Stage 2 of 4: Rewrite

Using the source and the decomposition, write a complete new version that:

- keeps every claim, fact, and relationship in the decomposition;
- uses substantially different sentences, phrasing, paragraph order, and transitions;
- reads as natural prose, not a mechanical paraphrase;
- follows the settings.

You may reorganize sections when the logic stays intact. Don't add claims, evidence, or interpretations the source doesn't support, and don't drop anything the decomposition marks as essential.

Return only the rewritten document.
