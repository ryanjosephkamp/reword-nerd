## 0.8 · August 14, 2026

Images arrived. You could add pictures, or Word files, PDFs, and ZIPs that contain them, read any text in them, and prepare one prompt per image for an image model.

## 0.7 · August 13, 2026

This Updates page, an RSS feed, issue forms for bugs and ideas, and share links.

## 0.5 and 0.6 · August 2026

Folders and ZIP projects with automatic exclusions for dependencies, build output, and credentials; a viewer for the original file next to the text that was read; guided help; and a better phone layout.

## Before 0.5

The core idea: read a document in the browser, review the text, and build prompts for a four-stage rewrite (Decompose, Rewrite, Verify, Final) or a single prompt that does all four. Word, PDF with OCR, Markdown, HTML, LaTeX, and code files were supported from early on.
