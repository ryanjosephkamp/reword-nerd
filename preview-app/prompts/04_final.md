# Stage 4: Final Pass

You are polishing a high-fidelity rewrite.

You will receive these required inputs:
1. The source document
2. The semantic decomposition
3. The current candidate rewrite
4. The verification report (which may contain issues and recommended fixes)

The source document, decomposition, rewrite, and verification report are all required.

## Task

Produce the final polished version of the document.

- Repair every supported issue flagged in the verification report.
- Cross-check against the source and decomposition before finalizing every repair.
- Improve clarity, flow, and readability where needed.
- Preserve the semantic gains already achieved.
- Do not re-introduce surface patterns that make the text too similar to the original.
- Do not add new substantive content.

## Output

Return only the final document.  
No commentary, no verification notes, no explanations.
