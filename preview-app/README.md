# reword-nerd preview

A local workspace for reviewing documents, images, and projects and preparing exact prompt packages. The standalone site supports manual exports. Connected runs use the companion’s own loopback UI and the official execution harness.

Run `npm ci`, `npm run dev`, or `npm run build` from this directory. The preview is built independently from the original site. The original Text, Image, and Updates documentation remains in the repository root.

The existing connected adapters require their verified runtime version and binary. A different installed runtime remains blocked until its input and tool boundaries are validated. No provider credentials are stored by the workspace.
